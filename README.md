# Personal Project Tracker

เว็บแอปเล็กๆ สำหรับติดตามโครงการส่วนตัว ออกแบบให้ใช้บนแท็บเล็ตเป็นหลัก และใช้บนเดสก์ท็อปได้ด้วย

ข้อมูลเก็บใน **Supabase** (ฐานข้อมูลบนคลาวด์ฟรี) ผูกกับบัญชีอีเมลของท่าน
เปิดจาก iPad หรือจากคอมพิวเตอร์ก็เห็นข้อมูลชุดเดียวกัน

**ใช้ได้เจ้าของคนเดียว** — แอปไม่มีปุ่มสมัครสมาชิก และฐานข้อมูลถูกล็อกให้เฉพาะบัญชีเจ้าของ
(ดูหัวข้อ "ความปลอดภัย" ท้ายไฟล์)
เวลาไม่มีอินเทอร์เน็ต แอปยังแสดงข้อมูลชุดล่าสุดให้อ่านได้ แต่แก้ไขไม่ได้จนกว่าเน็ตจะกลับมา

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ — หน้าล็อกอิน, หน้ารวมโครงการ, หน้ารายละเอียด, ฟอร์ม, กล่องยืนยัน |
| `style.css` | หน้าตาทั้งหมด สี ระยะ การ์ด ปุ่ม การปรับตามขนาดจอ รองรับโหมดมืด |
| `app.js` | การทำงานทั้งหมด — ล็อกอิน, อ่าน/เขียน Supabase, แคชออฟไลน์, เพิ่ม แก้ไข ลบ |
| `supabase-config.js` | **ไฟล์เดียวที่ท่านต้องแก้** — ใส่ Project URL และ anon key |
| `supabase-setup.sql` | SQL สำหรับสร้างตารางและตั้งค่าความปลอดภัย (คัดลอกไปวางใน Supabase ครั้งเดียว) |
| `supabase-owner-lock.sql` | SQL ล็อกให้เหลือ**เจ้าของคนเดียว** (ใส่ User UID ของท่านก่อนรัน) |
| `vendor/supabase.js` | ไลบรารี Supabase ฝังไว้ในโปรเจกต์ เพื่อให้เปิดได้แม้ตอนไม่มีเน็ต |
| `README.md` | ไฟล์นี้ |

ไม่มี framework ไม่ต้อง `npm install` ไม่ต้อง build

## การติดตั้ง — ทำครั้งเดียว

### ขั้นที่ 1 — สร้างโปรเจกต์ Supabase (ฟรี)

1. ไปที่ https://supabase.com กด **Start your project** แล้วสมัครด้วยบัญชี GitHub หรืออีเมล
2. กด **New project**
   - **Name**: `project-tracker`
   - **Database Password**: กดสุ่มแล้วเก็บไว้ในที่ปลอดภัย (ใช้ตอนเข้าฐานข้อมูลโดยตรง ไม่ใช่รหัสล็อกอินแอป)
   - **Region**: `Southeast Asia (Singapore)` — ใกล้ไทยที่สุด เร็วที่สุด
3. กด **Create new project** แล้วรอประมาณ 2 นาที

### ขั้นที่ 2 — สร้างตารางและตั้งค่าความปลอดภัย

1. เมนูซ้าย → **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase-setup.sql` คัดลอก **ทั้งไฟล์** ไปวาง
3. กด **Run** — ถ้าขึ้น `Success. No rows returned` แปลว่าเรียบร้อย

SQL นี้จะสร้างตาราง `projects` และเปิด **Row Level Security** ซึ่งเป็นสิ่งที่ทำให้
แต่ละบัญชีเห็นเฉพาะข้อมูลของตัวเอง แม้ anon key จะเปิดเผยต่อสาธารณะ

### ขั้นที่ 3 — สร้างบัญชีเจ้าของ (จาก Supabase โดยตรง)

แอปไม่มีปุ่มสมัคร จึงสร้างบัญชีที่ dashboard:

1. **Authentication** → **Users** → **Add user** → **Create new user**
2. กรอกอีเมลและรหัสผ่านที่ท่านจะใช้ล็อกอิน
3. ติ๊ก **Auto Confirm User** (ไม่ต้องรอยืนยันทางอีเมล) → **Create user**
4. ในรายชื่อ Users จะเห็นบัญชีท่าน — **คัดลอกค่า User UID** (ข้อความยาวรูปแบบ `a1b2c3d4-…`) เก็บไว้ใช้ขั้นถัดไป

### ขั้นที่ 4 — ล็อกให้เหลือเจ้าของคนเดียว

1. เปิดไฟล์ `supabase-owner-lock.sql` หาข้อความ `OWNER_UUID_HERE` (มี **จุดเดียว**) แทนที่ด้วย User UID จากขั้นที่ 3
   โดยเก็บเครื่องหมาย `'` ไว้ เช่น `'a1b2c3d4-0000-0000-0000-000000000000'::uuid`
2. **SQL Editor** → **New query** → วางทั้งไฟล์ → **Run**

ถ้าลืมแทนที่ข้อความ สคริปต์จะฟ้อง `invalid input syntax for type uuid` และไม่เปลี่ยนอะไรเลย (ไม่ทำให้ท่านถูกล็อกออก) แก้แล้วรันใหม่ได้

หลังขั้นนี้ แม้จะมีบัญชีอื่นโผล่มาในระบบ ก็จะอ่านและเขียนข้อมูลโครงการไม่ได้เลย

### ขั้นที่ 5 — ปิดการสมัครสมาชิก

**Authentication** → **Sign In / Providers** → ส่วน **User Signups** (ด้านบนของหน้า) → ปิดสวิตช์ **Allow new users to sign up** (ให้เป็นสีเทา)

จากนั้นไปที่ **Authentication** → **Users** ตรวจว่ามี**บัญชีเดียว** คือของท่าน

### ขั้นที่ 6 — คัดลอกค่า 2 ค่ามาใส่ไฟล์

1. **Project Settings** → **API Keys**
2. คัดลอก **Project URL** (ดูได้ที่ Data API ตัด `/rest/v1/` ท้ายออก) และ **Publishable key** (`sb_publishable_…`)
3. เปิดไฟล์ `supabase-config.js` วางทับข้อความ `PASTE_...` ทั้งสองจุด แล้วบันทึก

```js
window.SUPABASE_URL      = 'https://xxxxxxxx.supabase.co';
window.SUPABASE_ANON_KEY = 'sb_publishable_...';
```

> Publishable key (หรือ anon key แบบเดิม) เปิดเผยต่อสาธารณะได้โดยการออกแบบ ไม่ใช่ความลับ
> สิ่งที่ปกป้องข้อมูลจริงๆ คือ Row Level Security + การล็อกเจ้าของ ในขั้นที่ 2 และ 4
> แต่ **ห้ามนำ Secret key / `service_role` key มาใส่เด็ดขาด** — อันนั้นคือกุญแจผ่านทุกด่าน

### ขั้นที่ 7 — เปิดแอปและล็อกอิน

เปิดแอป (ดูหัวข้อถัดไป) แล้วล็อกอินด้วยอีเมลและรหัสผ่านจากขั้นที่ 3

## วิธีเปิดใช้งาน

### บนคอมพิวเตอร์
ดับเบิลคลิกไฟล์ `index.html`

### บนแท็บเล็ต / iPad (แนะนำ)
1. หน้า repository บน GitHub → **Settings** → **Pages**
2. Source เลือก **Deploy from a branch** → branch ที่ต้องการ → โฟลเดอร์ `/ (root)` → **Save**
3. รอ ~1 นาที จะได้ลิงก์ เช่น `https://qualitymiang-cpu.github.io/Personal-Project-Tracker/`
4. เปิดลิงก์บน iPad ด้วย Safari → ปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**

### ทดสอบบนเครื่องตัวเอง
```bash

# แล้วเปิด http://localhost:8123
```

## วิธีใช้งาน

- **หน้ารวมโครงการ** — การ์ดแต่ละใบบอก ชื่อโครงการ / สถานะ / ความคืบหน้า % / งานถัดไป / วันครบกำหนด
- **แตะที่การ์ด** เพื่อดูรายละเอียด — เป้าหมาย, สถานะปัจจุบัน, งานที่ทำเสร็จแล้ว, งานถัดไป, บันทึก
- **+ New Project** — เพิ่มโครงการใหม่ (ต้องกรอกชื่ออย่างน้อย 1 ช่อง)
- **Edit project** / **Delete project** — แก้ไขหรือลบ โดยการลบมีกล่องยืนยันก่อนเสมอ
- **Sign out** (มุมขวาบน) — ออกจากระบบ และล้างสำเนาข้อมูลออฟไลน์ของบัญชีนี้ออกจากเครื่อง (ปลอดภัยเมื่อใช้เครื่องร่วมกับผู้อื่น)
- **Reset to sample data** (มุมล่างขวา) — ลบทุกโครงการในบัญชีแล้วใส่ตัวอย่าง 4 โครงการ มีกล่องยืนยันก่อนเสมอ

**เคล็ดลับ:** ช่อง *Completed Work* และ *Next Actions* พิมพ์ **บรรทัดละ 1 รายการ**
บรรทัดแรกของ Next Actions คือสิ่งที่ไปแสดงบนการ์ดหน้าแรก

**ย้ายข้อมูลจากเวอร์ชันเดิม:** ถ้าเบราว์เซอร์นี้เคยใช้เวอร์ชัน localStorage มาก่อน
พอล็อกอินแล้วบัญชียังว่าง แอปจะถามว่าต้องการคัดลอกโครงการเดิมขึ้นคลาวด์ไหม
ข้อมูลเดิมในเครื่องจะไม่ถูกลบ

## ความปลอดภัย (เจ้าของคนเดียว)

ป้องกันเป็น 3 ชั้น เพราะลิงก์เว็บและ publishable key เปิดเผยต่อสาธารณะ จึงต้องกันที่ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่ม:

1. **ปิดการสมัคร** (Supabase) — ไม่มีใครสร้างบัญชีใหม่ได้
2. **ล็อกที่ฐานข้อมูล** (`supabase-owner-lock.sql`) — เฉพาะ User UID ของเจ้าของเท่านั้นที่อ่าน/เขียนตาราง `projects` ได้ แม้มีบัญชีอื่นก็ทำอะไรไม่ได้
3. **แอปไม่มีปุ่มสมัคร** — เป็นแค่ความเรียบร้อยของหน้าจอ ไม่ใช่ตัวป้องกันจริง

**เปลี่ยนเจ้าของ:** แก้ UID ในไฟล์ล็อกแล้วรันใหม่ได้ปลอดภัย

## ลืมรหัสผ่าน

ยังไม่มีปุ่ม "ลืมรหัสผ่าน" ในแอป ให้ตั้งใหม่ที่ Supabase → **SQL Editor** (แก้ 2 จุดก่อนรัน):

```sql
update auth.users
set encrypted_password = extensions.crypt('รหัสผ่านใหม่', extensions.gen_salt('bf')),
    updated_at = now()
where email = 'อีเมลของท่าน';
```

ถ้าขึ้นว่า `function extensions.crypt does not exist` ให้ตัดคำว่า `extensions.` ออกทั้งสองจุด

## เรื่องออฟไลน์

ทุกครั้งที่โหลดข้อมูลสำเร็จ แอปจะเก็บสำเนาไว้ในเครื่อง เวลาเน็ตหลุด:

- ยังเปิดดูโครงการทั้งหมดได้ตามปกติ
- มีแถบสีเหลืองแจ้งเตือนด้านบน พร้อมปุ่ม **Try again**
- ปุ่มเพิ่ม / แก้ไข / ลบ จะเป็นสีจาง กดไม่ได้ เพื่อไม่ให้แก้แล้วข้อมูลหาย
- พอเน็ตกลับมา แอปจะโหลดใหม่เองอัตโนมัติ
