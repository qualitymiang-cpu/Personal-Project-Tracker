# Personal Project Tracker

เว็บแอปเล็กๆ สำหรับติดตามโครงการส่วนตัว ออกแบบให้ใช้บนแท็บเล็ตเป็นหลัก และใช้บนเดสก์ท็อปได้ด้วย

ข้อมูลทั้งหมดเก็บอยู่ใน **เบราว์เซอร์ของท่านเท่านั้น** (localStorage) ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่มีการส่งข้อมูลออกไปที่ใด

---

## ไฟล์ในโปรเจกต์ (4 ไฟล์)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงสร้างหน้าเว็บทั้งหมด — หน้ารวมโครงการ, หน้ารายละเอียด, ฟอร์ม, กล่องยืนยัน |
| `style.css` | หน้าตาทั้งหมด — สี ระยะห่าง การ์ด ปุ่ม และการปรับตามขนาดจอ |
| `app.js` | การทำงานทั้งหมด — อ่าน/เขียน localStorage, เพิ่ม แก้ไข ลบ, ข้อมูลตัวอย่าง 4 โครงการ |
| `README.md` | ไฟล์นี้ |

ไม่มี framework ไม่ต้อง `npm install` ไม่ต้อง build เปิดไฟล์ก็ใช้ได้เลย

## วิธีเปิดใช้งาน

### บนคอมพิวเตอร์ (ง่ายที่สุด)
ดับเบิลคลิกไฟล์ `index.html` — เบราว์เซอร์จะเปิดแอปขึ้นมาทันที

### บนแท็บเล็ต / iPad (แนะนำ)
วิธีที่สะดวกที่สุดคือเปิดผ่าน GitHub Pages เพื่อให้ได้ลิงก์ที่เปิดจาก iPad ได้เลย

1. ไปที่หน้า repository นี้บน GitHub → **Settings** → **Pages**
2. ที่ Source เลือก **Deploy from a branch**
3. เลือก branch `claude/personal-project-tracker-w7m4ba` (หรือ `main` หลังจาก merge แล้ว) และโฟลเดอร์ `/ (root)` → **Save**
4. รอประมาณ 1 นาที GitHub จะให้ลิงก์มา เช่น
   `https://qualitymiang-cpu.github.io/personal-project-tracker/`
5. เปิดลิงก์นั้นบน iPad ด้วย Safari
6. กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
   จะได้ไอคอนเหมือนแอปจริง เปิดแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์

### ทดสอบบนเครื่องตัวเอง (สำหรับนักพัฒนา)
```bash
python3 -m http.server 8123
# แล้วเปิด http://localhost:8123
```

## วิธีใช้งาน

- **หน้ารวมโครงการ (Dashboard)** — เห็นทุกโครงการเป็นการ์ด แต่ละใบบอก ชื่อโครงการ / สถานะ / ความคืบหน้า % / งานถัดไป / วันครบกำหนด
- **แตะที่การ์ด** เพื่อดูรายละเอียด — เป้าหมาย, สถานะปัจจุบัน, งานที่ทำเสร็จแล้ว, งานถัดไป, บันทึก
- **+ New Project** — เพิ่มโครงการใหม่ (ต้องกรอกชื่อโครงการอย่างน้อย 1 ช่อง)
- **Edit project** — แก้ไขได้ทุกช่อง
- **Delete project** — ลบ โดยมีกล่องยืนยันก่อนเสมอ
- **Reset to sample data** (มุมล่างขวา) — ล้างทุกอย่างแล้วกลับไปเป็นข้อมูลตัวอย่าง 4 โครงการ มีกล่องยืนยันก่อนเสมอ

**เคล็ดลับ:** ช่อง *Completed Work* และ *Next Actions* ให้พิมพ์ **บรรทัดละ 1 รายการ**
บรรทัดแรกของ Next Actions คือสิ่งที่ไปแสดงบนการ์ดหน้าแรก

## เรื่องข้อมูล

- บันทึกอัตโนมัติทุกครั้งที่กด Save หรือ Delete
- ข้อมูลผูกกับ **เบราว์เซอร์ + เครื่องนั้น** เท่านั้น เปิดจาก iPad กับจากคอม จะเห็นคนละชุด
- ล้างข้อมูลเบราว์เซอร์ (Clear website data) = ข้อมูลโครงการหายด้วย
- โหมดท่องเว็บส่วนตัว (Private Browsing) จะบันทึกไม่ได้ แอปจะเตือนให้ทราบ
- ข้อมูลตัวอย่างจะโหลด **ครั้งแรกครั้งเดียว** ถ้าลบโครงการจนหมด ตัวอย่างจะไม่กลับมาเอง (มีปุ่มให้กดโหลดเองถ้าต้องการ)
